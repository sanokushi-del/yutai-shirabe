プライバシーポリシー

現在の状況

  • このサイトは、アクセス解析のサービスを使っていません。広告も配信していません。Cookie も使っていません。
  • 各ページは、外部のスクリプト・フォント・画像を読み込みません。ページの表示のために、利用者の情報を第三者へ送信することはありません。
  • 優待利回りの計算欄に入力した株価は、お使いのブラウザの中だけで計算します。送信も保存もしません。
  • 条件で探す欄の絞り込みも、ブラウザの中だけで行います。
  • このサイトは GitHub Pages（GitHub, Inc.）から配信しています。配信の仕組み上、GitHub がアクセスの記録（IP アドレスなど）を安全のために取得・保存することがあります。扱いは GitHub のプライバシーに関する声明によります。

今後、アクセス解析や広告を入れるとき

アクセス解析や広告（Google アドセンスなど）を入れる前に、このページに次の内容を書きます。

  • 使うサービスの名前と目的
  • 使う Cookie などの識別情報の種類と、保存の期間
  • 外部へ送信される情報の内容と、送信先（事業者名）
  • 利用者が、送信や Cookie を止める方法
