権利落ちの前後の値動きの統計

この統計の見方

  • 優待の権利付き最終日（t0）の前後で、株価がどう動いたかを、会社と年をまとめて集計した値です。
  • 先回り = t0 の20営業日前から t0 まで、権利落ち = t0 から翌営業日まで、落ちた後 = 権利落ちの翌営業日から10営業日後までの、調整後終値の騰落率です。
  • 超過 = 優待のない同じ決算月の会社の平均との差です。権利落ちでは、配当の権利落ちによる下落も株価に含まれます。その影響を薄めるために、超過を主な値として出しています。ただし、配当の違いは完全には取り除けていません。対照群の社数が10社に満たない出来事は、超過を出していません。
  • そのままの騰落率は、薄い色の「参考」の列に並べています。配当の権利落ちの分も入っているので、優待だけの影響を示す値ではありません。
  • 載せているのは、件数・平均・平均の95%区間だけです。個々の会社の株価や騰落率は載せていません。件数が少ない段は、平均を出していません。
  • 95%区間は、権利付き最終日の日付ごとにまとめて計算しています（同じ日の出来事は相場全体と一緒に動くため）。日付の数が少ない段は区間を出していません。
  • 観察された傾向を集計しただけで、原因を示すものではありません。過去の傾向が今後も続くとは限りません。特定の銘柄の売買を勧めるものではありません。

  • 株価のデータは J-Quants API から取得したものを、運営者が集計しました。このページに載せているのは集計した値だけで、株価そのものは載せていません。
