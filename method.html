データの作り方と限界

データの作り方

  1. EDINET（金融庁の開示システム）の API から、上場会社の有価証券報告書（有報）を取得します。取得するのは各社の最新の有報です。
  2. 有報の「株式事務の概要」にある「株主に対する特典」欄を、規則（プログラム）で読み取ります。優待の有無・権利月・基準日・必要株数・継続保有の条件・優待の種類・金額を項目にします。
  3. 基準日から、権利付き最終日と権利落ち日を計算します。取引所の休業日は、祝日法の決まりと年末年始の休業日から計算しています。
  4. 上場している会社だけを載せます。上場を終えた会社のページは作りません。
  5. 特典欄の文章は提出会社が書いたものなので、転載しません。載せるのは項目（日付・株数・条件・種類・金額の推定・印）だけです。

項目の意味

  • 基準日：優待の権利が確定する日。月ごとに日付を読み取り、「末日」は月の最後の日として扱います。
  • 必要株数：優待を受けられる最小の株数（最小の段）。
  • 継続保有（必須）：優待を受けるのに必須の継続保有期間のうち、読み取れた最短のもの。必須も長期優遇も読み取れなかった会社は「条件の記載なし」と出しています（読み取りの漏れを含むことがあり、条件が無いと言い切るものではありません）。
  • 長期優遇：必須ではないが、長く持つと優待が増える・追加される記載があるもの。
  • 優待の種類：特典欄の語から決めた12種類と「不明」。1社が複数の種類に入ります。「不明」のうち、特典欄に優待の中身を述べる語（品・券・ポイント・割引・贈呈・送付など）が見当たらない会社は、「記載なし」と出します。
  • 金額：本文に金額・枚数・ポイントの換算が書かれた優待だけを円に換算した推定。1回は最小の段、1年は回数をかけたものです。
  • 年額に添える理由：年額を出せないときは、その理由を添えています。「割引のため金額にできません」は割引の率だけでもらえる金額の記載が見当たらないもの、「ポイント（円との換算の記載なし）」はポイントの数だけで円との換算が書かれていないもの、「金額の記載なし」は特典欄に円の金額が見当たらないもの、「1回 N円相当（年の回数は読み取れず）」は1回の金額は読めたが年の回数（基準日の数）が分からないもの、「金額は上の段のみ（最小の段は金額の記載なし）」は円の金額が上の段（より多い株数の段や長い保有期間の欄）にだけ書かれていて、最小の段には円の金額が見当たらないもの、「読み取れず」は円の金額があるのに規則で金額にできなかったものです。
  • 印：新設・変更・廃止などの語が特典欄にあること、決算に株主優待引当金の項目があること、基準日を推定で補ったこと、など。
  • 「記載なし」と「読み取れず」：必要株数と基準日が空のとき、特典欄に株数や日付の手がかりとなる語が見当たらなければ「記載なし」（読み損ないではなく、書かれていないもの）、手がかりはあるのに規則で値にできなければ「読み取れず」と出します。手がかりの語は、必要株数なら「N株」「単元」「単位」など、基準日なら「N月」「月末」「期末」「基準日」などです。主な種類が決まらなかったときも同じで、優待の中身を述べる語（品・券・ポイント・割引・贈呈・送付など）が見当たらなければ「記載なし」、語はあるのに規則で種類が決まらなければ「読み取れず」（表では「不明」）と出します。

株価から計算した値

会社ページの「株価から計算した値」は、J-Quants API の株価（終値）と財務の要約（決算短信の数字と予想）、有価証券報告書から読み取った必要株数と年額の推定から、運営者が計算した値です。計算の基準の日は 2026-10-20 で、基準の日から14日以内でいちばん新しい終値を使っています（会社ごとの終値の日は、各ページの見出しに書いています）。

  • 最低投資額：終値 × 必要株数（最小の段）。円に丸めます。
  • 優待利回り：優待の年額の推定 ÷ 最低投資額。年額の推定が無い会社は出しません。
  • 配当利回り：予想年間配当 ÷ 終値。予想年間配当は決算短信の予想で、年間の値が無いときは期末などの予想の合計で補います（その旨の印を添えます）。配当の予想が無い会社は出しません。
  • 総合利回り：優待利回り + 配当利回り。どちらかが無いときは出しません。
  • PER：終値 ÷ 予想EPS（予想の1株あたり利益）。予想EPSが無い・0以下の会社は出しません。
  • PBR：終値 ÷ 1株あたり純資産（最新の本決算の値。無いときは、純資産 ÷（発行済株式数 − 自己株式数）で計算し、その旨の印を添えます）。0以下の会社は出しません。
  • 値が無いものは「—」と出しています。終値が見つからない、財務の予想が無い、必要株数や年額の推定を読み取れていない、のいずれかです。
  • 株式の分割・併合が決算の開示より後にあった会社は、1株あたりの予想や純資産を、その比率で直しています（印を添えます）。優待の必要株数と金額は有価証券報告書のままで、分割に伴う変更は反映できません。
  • 優待の年額の推定は推定です。上の「項目の意味」にあるとおり、選択式の優待などでは実際と違うことがあります。
  • 株価は日々変わります。ここの値は、基準の日の終値で計算した、ある日の姿です。今後の値を示すものではありません。
  • 終値そのもの、銘柄ごとの株価は載せていません。載せているのは、上の式で計算した値だけです。
  • 割安・割高や売買を判断するものではありません。

限界（先にお読みください）

  • 有報は年に1回です。期中に優待が新設・変更・廃止されても、次の有報が出るまで（最大1年）は反映されません。
  • 有報の特典欄に優待を書かない会社があります。優待を実施していても載っていない会社があるため、このサイトは「有報に書かれている優待の一覧」です。印「引当金あり」は、優待があった手がかりにすぎません。
  • 読み取りは規則による推定で、誤りが残ります。基準日・株数・金額を間違えることがあります。印が付いた項目は、特に確かさが低いものです。
  • 割引率や品名だけの優待、抽選の優待は金額を読めません。複数の段がある優待は最小の段を載せています。
  • 選択式の優待（いずれかを選ぶ）や、基準日が複数あっても優待は年1回の会社では、年の金額が実際と違うことがあります。
  • 権利付き最終日は、通常の営業日の数え方による計算です。取引所の臨時休業・売買停止、祝日法の改正は反映できません。

既知の誤り

見つけた誤りは規則を直して反映していますが、直せていない型が残っています（上の「限界」に書いた、選択式の優待の年額など）。誤りを見つけたときは、お問い合わせから、会社名・コード・違っている項目・根拠（有報のどこに何と書かれているか）を添えてお知らせください。
